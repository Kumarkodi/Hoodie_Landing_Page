# Hoodie Landing Page

A modern, visually appealing landing page for a hoodie e-commerce store, built using HTML and CSS.

## Overview

**Hoodie Landing Page** is a stylish and responsive website for showcasing hoodie products. The landing page features a hero section, product catalog, customer reviews, and contact information, making it perfect for any apparel business.

## Features

- Responsive navigation bar with a burger menu
- Hero section with a promotional message and call-to-action buttons
- Featured sale section (e.g., Summer Sell Offer)
- Product showcase with images, names, and prices
- Product categories: New Arrivals, Top Rating, Best Seller
- Customer testimonials
- Footer with location, working hours, and contact information
- Custom images and professional styles

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kumarkodi/Hoodie_Landing_Page.git
   ```
2. **Open `index.html` in your browser to view the landing page.**

## Customization

- Replace hoodie images in the `image/Product/` directory with your own product photos.
- Edit text, links, and styles in `index.html` and `style.css` as needed for your brand.
